# 商汤小浣熊 × 51CTO AI办公专区

交互式网页设计原型，包含企业案例、AI办公场景、课程与认证展示。

## 在线预览
https://nniro691-sudo.github.io/xiaohuanxiong-ai-work/

## 本地开发
```sh
npm ci
npm run dev
```

## 构建与独立文件
```sh
npm run build
node scripts/export-single-html.mjs
```

GitHub Pages 使用 `docs/index.html`。此文件已内嵌样式、脚本与图片，可独立打开。更新后将新导出的 HTML 复制到该路径并提交。

企业场景图片为AI生成示意；部分课程、认证及详情链接仍为原型占位。品牌与Logo归各自权利人所有。
